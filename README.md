# 工业互联网习题

用于“2026秋—工业互联网选择题测试”的篡改猴（Tampermonkey）脚本，内置提供的 40 道题答案，支持单选题、多选题和判断题。

## 使用方法

1. 在浏览器中安装篡改猴或者其他脚本插件。
2. 打开本仓库的 `工业互联网作业填答.user.js` 文件，复制全部代码。
3. 点击篡改猴图标，选择“添加新脚本”，用复制的代码替换默认内容，按 `Ctrl + S` 保存。
4. 点击页面右上方的“按答案填答并提交”蓝色按钮。

脚本会检查 40 道题的题干和选项，按内置答案选择，并在全部检查通过后点击“提交作答”。若出现提交确认弹窗，需要手动确认；最终是否提交成功，以页面显示为准。
